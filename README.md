# Starter Minimal Mistakes — Site perso (GitHub Pages)

## Utilisation rapide
1. Éditez `_config.yml` (nom, bio, liens).
2. Ajoutez votre CV à `assets/cv.pdf`.
3. Remplacez `assets/images/hero.jpg` et `assets/images/avatar.jpg`.
4. Ajoutez/éditez vos fichiers dans `_projects/` (un fichier par projet).
5. Poussez sur `main`. GitHub Pages publiera automatiquement sur https://theoriginalmmm.github.io

## Local (optionnel)
- Installez Ruby + Bundler, puis :
  ```
  bundle install
  bundle exec jekyll serve
  ```
  Ouvrez http://127.0.0.1:4000
