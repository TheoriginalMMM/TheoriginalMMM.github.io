## System

Designed and implemented an intelligent table-football environment combining embedded sensing, computer vision and a real-time control interface.

## Main components

- Arduino-based acquisition and piezoelectric sensors for physical events.
- Webcam and YOLO object detection for visual game monitoring.
- Real-time web application for game control, score monitoring and interaction.
- Integration of heterogeneous hardware and software components into a demonstrable prototype.
