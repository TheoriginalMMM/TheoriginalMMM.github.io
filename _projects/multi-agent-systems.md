## Implemented projects

- Multi-agent flight-ticket negotiation and sales system using automatic negotiation and cognitive agents.
- Collective-sorting system based on interactive agents and self-organisation.
- Multi-agent Mars exploration simulation using a belief-desire-intention architecture with JADE.
- Distributed sliding-puzzle game comparing several cognitive-agent strategies.

These projects developed practical skills in distributed decision-making, agent communication, coordination protocols and emergent collective behaviour.
